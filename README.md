# FMS

ここまで作成したFortnite大会管理システムの更新版ソース一式です。

最新のFMSロゴ、サイドバーの旗・歯車アイコン、設定の位置調整まで反映しています。

## 起動方法（Windows）

ZIPを展開し、`START_WINDOWS.bat` を開いてください。Python 3が必要です。
ブラウザが自動で開きます。終了は起動した画面で Ctrl+C を押してください。

コマンドで起動する場合は、このフォルダーで `python start.py` を実行してください。

## 現時点の機能

- ダブルサイドバー、大会概要、大会切り替え
- 予選・決勝・任意区分の追加、区分別の配点・集計履歴・順位表設定
- チーム一覧、選手一覧、選手CSV出力
- Discord登録パネルと定型文の設定・プレビュー
- CSV読み込み、複数マッチ集計、EpicID照合
- 順位表プレビュー、タイトル選択による総合集計、背景選択
- PNG・SVG・OBS用HTML出力
- サンプルのログイン導線、サーバー選択、アカウント変更・ログアウト

## 現在の制限

実際のDiscordログイン・サーバー取得・登録受付・カテゴリやロール等の自動作成は未接続です。
Discordアプリ、Bot、認証やデータ共有を行うサーバー側処理の実装が必要です。
このZIPにBotの実装や認証情報は含まれていません。

保存先は、使用中のブラウザのローカルストレージです。別の端末・ブラウザ・URLとは共有されません。
公開サイトで入力したデータは、このZIPには含まれません。
大会概要の締切・最大チーム数は保存のみで、Discord受付にはまだ反映されません。
OBS用HTMLは書き出した時点の固定表示です。

## ファイル

- `index.html` — 管理画面・スタイル
- `app.js` — チーム・選手・Discordパネル等
- `auth.js` — サンプル認証導線・サーバー選択・大会管理
- `stages.js` — 大会区分・予選決勝管理
- `match.js` — CSV解析・集計・選手照合・履歴
- `leaderboard.js` — 順位表・配信用アセット出力
- `assets/fms-icon.png` — FMSロゴ・ブラウザアイコン
- `start.py` / `START_WINDOWS.bat` — ローカル起動
